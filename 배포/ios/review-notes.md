# App Review 메모 초안

```text
오레노라멘 임직원 전용 레시피 학습 앱입니다. 앱의 핵심 기능은 직원별 학습, 시험, 오답 분석 및 사내 공지 확인입니다.

심사용 계정
이메일: REPLACE_REVIEW_EMAIL
비밀번호: REPLACE_REVIEW_PASSWORD

심사용 계정은 가입 승인 완료 상태이며 일반 직원 권한입니다. 로그인 후 모든 일반 사용자 기능을 확인할 수 있습니다.

첫 로그인 완료 시 새 공지, 가입 심사 결과 및 직원 등급 변경 알림의 용도를 먼저 설명합니다. 검토자가 '알림 받기'를 선택한 경우에만 iOS 시스템 알림 권한 요청이 표시되며, '나중에'를 선택해도 핵심 기능을 모두 사용할 수 있습니다.

알림 설정 경로: 홈 → 설정 → 알림 받기
계정 삭제 경로: 홈 → 설정 → 계정 영구 삭제
비밀번호 복구 경로: 로그인 → 비밀번호를 잊으셨나요?
개인정보처리방침 및 고객지원: 로그인 화면 하단 또는 홈 → 설정 → 도움말 및 정책
```

실제 계정 정보는 이 파일에 저장하지 말고 App Store Connect의 App Review Information에만 입력한다.

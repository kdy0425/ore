# App Store 개인정보 설문 초안

최종 제출 전 실제 운영 및 Supabase 처리 범위를 검토한다.

## 수집하는 데이터

| Apple 데이터 유형 | 연결 여부 | 추적 여부 | 목적 |
|---|---:|---:|---|
| 이름 | 사용자와 연결 | 추적 안 함 | 앱 기능, 계정 관리 |
| 이메일 주소 | 사용자와 연결 | 추적 안 함 | 인증, 계정 복구 |
| 전화번호 | 사용자와 연결 | 추적 안 함 | 직원 식별 |
| 사용자 ID | 사용자와 연결 | 추적 안 함 | 인증 및 데이터 연결 |
| 기기 ID | 사용자와 연결 | 추적 안 함 | 사용자가 동의한 푸시 알림 전송 |
| 제품 상호작용 | 사용자와 연결 | 추적 안 함 | 학습·시험·통계 제공 |
| 사진 또는 비디오 | 관리자와 연결 | 추적 안 함 | 공지 이미지 제공 |
| 기타 사용자 콘텐츠 | 관리자와 연결 | 추적 안 함 | 공지 제목·본문 제공 |

- 광고 없음
- 제3자 광고 추적 없음
- 위치, 연락처, 결제정보, 건강정보 수집 없음
- Supabase는 인증·DB·파일 보관을 위한 처리 위탁 서비스
- Expo Push Service는 사용자가 동의한 공지·가입 심사·등급 변경 알림 전송 서비스
- 알림은 선택 기능이며 `설정 → 알림 받기`에서 언제든 해제 가능

## 계정 삭제

`설정 → 계정 영구 삭제`에서 계정과 연관 데이터를 삭제할 수 있다. 개인정보처리방침에는 보관 기간, 삭제 절차, 위탁 처리자를 명시해야 한다.

- 개인정보처리방침: `https://oreno-ramen-staff.vercel.app/privacy`
- 공개 계정 삭제 안내: `https://oreno-ramen-staff.vercel.app/account-deletion`

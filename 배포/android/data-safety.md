# Google Play 데이터 보안 설문 초안

최종 답변은 실제 운영·보관·위탁 계약과 대조해야 한다.

## 기본 답변

- 데이터를 수집하는가: 예
- 전송 중 암호화하는가: 예(HTTPS/TLS)
- 데이터 삭제 요청 방법을 제공하는가: 예(앱 내 `내 정보 → 계정 영구 삭제` 및 공개 삭제 안내 URL)
- 데이터를 판매하는가: 아니요
- 광고 목적으로 사용하는가: 아니요

## 수집 데이터와 목적

| Play 데이터 유형 | 실제 데이터 | 필수 여부 | 목적 |
|---|---|---:|---|
| 이름 | 직원 이름 | 필수 | 계정 및 직원 관리 |
| 이메일 주소 | 로그인 이메일 | 필수 | 인증, 계정 복구 |
| 전화번호 | 직원 휴대폰 번호 | 필수 | 직원 식별 및 운영 연락 |
| 사용자 ID | Supabase 사용자 UUID | 필수 | 계정·기록 연결 |
| 앱 활동 | 학습/시험 답변, 점수, 시간 | 앱 사용 시 | 학습 기능, 개인·지점 통계 |
| 사진 | 관리자가 선택한 공지 이미지 | 선택 | 공지 제공 |
| 기타 사용자 제작 콘텐츠 | 공지 제목과 본문 | 관리자만 선택 | 사내 공지 제공 |

Supabase는 인증·DB·Storage 처리 위탁자다. Play Console의 “공유” 정의와 서비스 제공자 예외 적용 여부는 운영 계약을 기준으로 최종 판단한다.

## 계정 삭제

- 앱 안에서 삭제 가능
- 공개 웹 삭제 요청 URL 필요
- 계정 삭제 시 프로필, 학습/시험 기록, 작성 공지 및 연관 이미지 삭제
- 레시피 버전처럼 다른 직원 운영에 필요한 비개인 데이터는 업로더 식별자만 제거하고 유지
